1. Project Overview

Clasmo Diagnostics is a multi-zone Laboratory Information Management System (LIMS). It covers patient search and registration, billing, barcode linking and scanning, sample workflow, clinical result entry, report verification, franchise wallets and pricing, administration masters, dashboards, reports, and home-collection device modules.

2. Quick start

Backend

cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_zones
python manage.py seed_test_roles
python manage.py seed_clinical_data
python manage.py runserver
# API: http://127.0.0.1:8000/api/

Frontend

cd frontend
npm install
npm run dev
# App: http://localhost:5173

Docker

docker-compose up
# API at http://localhost:8000
# Postgres: clasmo / clasmo / db clasmo

After production deploy, run python manage.py migrate.

11. Feature modules (what they do)

Registration / New Entry

Creates patient + registration + tests. Uses LabConfiguration.next_patient_sequence (no full-table MAX scan). Returns next_lab_code and next_patient_id. Debits franchise wallet and distributes cascade commissions. Clinical PDF upload is non-blocking after success.

Sample Accession

Reception and technician see all bookings in their zone regardless of creator role. Uses ReportSectionTable format (Booking ID, Patient, Barcodes, Ref By, Tests, Status).

Scan / Extra Sample

Scan or type barcode. If found, show patient/sample. If not found, option to save as Extra Sample. Extra samples are zone-scoped.

Scan Log

Audit of successful scans from PatientSampleScanView. Shows barcode, patient, lab code, sample type, scanned-by username, time. Reception/technician see own zone; global admins see all zones in separate sections. Historical scans before this feature are not backfilled.

Out Sources / Out Received

Send selected tests to partner labs; receive them back; optional report file upload. Row coloring indicates status.

Hold and Rejection

Staff place holds or reject samples by barcode. Franchise users see holds/rejections on their hierarchy entries.

Clinical

Parameter master (admin). Result entry (technician/admin). Pathologist verifies. Instrument ingest can post analyzer results. Public patient report lookup exists.

Franchise money

Per-user wallets. Booking charges debit the creator. Commissions credit Supreme → Prime → Sub cascade. Admin can top up/adjust. Online top-up for franchise. Bulk per-test rates and transfer pricing from parent to child franchisees. Report release can be blocked if wallet rules fail.

Zone isolation

Most operational data is filtered by user.zone. Super admin / selected global roles can see all zones.
